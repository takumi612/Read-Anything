Bản đồ mã nguồn

Trang này có đường dẫn tới từng tệp trong src, packages, scripts, assets, patches và các cấu hình gốc. Mở từng nhóm phía dưới để tra cứu.

Danh mục gồm 746 tệp trong 70 nhóm tại thời điểm tạo. Tạo lại danh sách so sánh bằng rg --files src packages scripts assets patches cùng các cấu hình ở thư mục gốc. File *.test.* là kiểm thử; file fixture.ts trong các parser và packages/ui-prototype/src/mock/fixtures.ts là dữ liệu mẫu; migration là lịch sử schema; packages/ui-prototype không thuộc build ứng dụng chính.
