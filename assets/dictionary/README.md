# Bundled English–Vietnamese dictionary

The unmodified SQLite data file is sourced from
[`skypediacode/english-vietnamese-dictionary`](https://github.com/skypediacode/english-vietnamese-dictionary)
at commit `388adc0826300912e5b0311c089e0e70494b065f`.

The upstream project reports approximately 104,829 English headwords and 158,307 meanings. Its database is licensed under
Creative Commons Attribution-ShareAlike 4.0 International (CC BY-SA 4.0). The required full attribution is in
[`ATTRIBUTION.md`](./ATTRIBUTION.md), distributed alongside the database. The application uses the database read-only and
does not modify or redistribute a transformed copy.

The source repository identifies MinhQND Dictionary, Wiktionary, vntk/dictionary, Hồ Ngọc Đức's Vietnamese Dictionary
Project, WikDict, and open-dict-data among the upstream sources. See `ATTRIBUTION.md` for the full provenance and license
notices.
